# QA Test Documentation Samples

A portfolio of the written side of testing: a **test plan**, **test cases**, **bug
reports** and a **release regression checklist**, all written for one sample
feature, an online store checkout.

Nine years of QA work taught me that clear documentation is half the job. A
defect only gets fixed quickly if someone else can reproduce it from the report.

| File | What it shows |
|---|---|
| [`test-plan.md`](test-plan.md) | Scope, risks, approach, entry and exit criteria |
| [`test-cases.csv`](test-cases.csv) | 20 cases covering positive, negative and boundary scenarios |
| [`bug-reports/`](bug-reports) | Three reports at different severities, each with reproduction steps |
| [`regression-checklist.md`](regression-checklist.md) | Smoke and regression checklist run before each release |

The product and bugs are fictional and written for demonstration.
